# CLAUDE.md

Guidance for Claude Code working in this repository.

**Starting a session: read `docs/slices.md` first** ("Where we are" and the
next slice), then `docs/explanation/design.md`. No plan lives anywhere else.

## Rules

- Documentation and commit messages in English. `docs/` follows Diátaxis
  (index in `README.md`), each fact in one place.
- The capture schema's reference is `docs/reference/capture-schema.md`;
  every adapter and reader follows it. Change it there first.
- This repo is public: no server addresses, pod paths of real people, or
  private project details in code, docs or examples.
- Nothing leaves a person's pod (reports, publications) without their
  validation; adapters may write raw traces without asking, nothing else.
